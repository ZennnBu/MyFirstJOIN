JoinPlus

A Professional Minecraft Paper Plugin for Custom Player Join & Quit Experiences.

JoinPlus is a customizable Minecraft server plugin designed to make player joining and leaving experiences more professional, interactive, and unique.

✨ Features

- Custom Join Messages
- Custom Quit Messages
- First Join Welcome Messages
- Join Titles & Subtitles
- ActionBar Messages
- Custom Join Sounds
- Join Particle Effects
- Custom Join Items
- Configurable Join Commands
- Permission-Based Messages
- MiniMessage & Hex Colors
- PlaceholderAPI Support
- Easy Configuration System
- Reload Commands
- Update Notifications

📦 Compatibility

- Platform: Paper
- Target Version: 26.2
- Java: 25
- Language: Java

🛠️ Commands

Command| Description
"/joinplus"| Main command
"/joinplus help"| View all commands
"/joinplus reload"| Reload configuration
"/joinplus info"| Plugin information
"/joinplus test"| Test join messages

🔐 Permissions

Permission| Description
"joinplus.admin"| Full plugin access
"joinplus.reload"| Reload configuration
"joinplus.test"| Test messages
"joinplus.bypass"| Bypass configured join features

⚙️ Configuration

JoinPlus will provide customizable YAML configuration files for messages, sounds, effects, permissions, and other features.

📥 Installation

1. Download the latest JoinPlus release.
2. Place the JAR file inside your server's "plugins" folder.
3. Restart your server.
4. Customize the configuration.
5. Enjoy JoinPlus!
